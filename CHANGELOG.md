# Changes

## v1.0.0 — 2 November 2026

* Precompiled native Apple Silicon P1008 raster filter and firmware converter.
* P1008-specific PPD and on-demand USB RAM firmware loader.
* Optional per-user USB offline/online monitor, with enable and disable commands.
* Local import of checksum-verified firmware from the user’s vendor download; no proprietary firmware in the public release.
* Installer checks device identity and pending jobs; uninstall targets only this package’s queue and files.
* Full corresponding source, build scripts, licence notices, setup guide and validation scope.
